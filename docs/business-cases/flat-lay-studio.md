# Flat-Lay Studio: Picture the Outfit Exactly How You Want It

## Overview

Every outfit in the Virtual Stylist comes with a flat-lay image — and with the Interactive Flat-Lay Studio, you're not stuck with the first picture. Describe the change you want, and the AI redraws the flat-lay to match: different shoes, an added coat, a new background, a seasonal touch. Keep iterating until the image looks exactly like the outfit you're imagining.

## Problem

A flat-lay is only helpful if it matches what you actually plan to wear. Maybe the shoes aren't your style, or you'd add a scarf, or you want to see the look against a different setting. With a static image, you're left mentally editing the picture — and mental edits are easy to get wrong when you're getting dressed.

## Solution

The Interactive Flat-Lay Studio opens for any outfit and puts you in the director's chair. It shows:

- A **live preview** of the current flat-lay.
- A **prompt input** where you describe any change in your own words.
- **Six one-click quick prompts** for common tweaks, such as swapping the shoes for crisp white minimalist leather sneakers, adding a vintage double-faced camel wool trench coat draped alongside, changing the background to dark weathered rustic oak floorboards, or making the look autumn-weather ready with a tailored cashmere scarf and leather gloves.

When you submit a prompt, the AI generates a new image that becomes the live preview. Every edit you make is added to an **edit history list**, so you can see exactly which prompts you've applied. Keep iterating as much as you like — then either **Apply** to replace the outfit's flat-lay image, or close without applying to keep the original.

If something goes wrong, you'll see a friendly inline message rather than a cryptic error.

## User Journey

1. Open any outfit in the showcase and launch the Interactive Flat-Lay Studio.
2. Look at the live preview of the current flat-lay.
3. Either type your own change into the prompt input, or click one of the six quick prompts for a common tweak.
4. Submit your prompt and watch the AI generate a new version of the flat-lay, which becomes the live preview.
5. Check the edit history list to see the prompts you've applied so far.
6. Keep iterating — swap pieces, add layers, change the background — until the image matches your vision.
7. Click Apply to make this image the outfit's flat-lay, or close the studio without applying to keep the original.

## Benefits

- See the outfit you'll actually wear, not a close approximation.
- Make changes in plain language — no design skills needed.
- Six quick prompts get you to common tweaks in a single click.
- A full edit history shows every prompt you've applied.
- Nothing is permanent: iterate freely, and only apply when you're happy.
- Friendly, clear error messages if anything goes wrong.

## How to Get Started

1. Generate an outfit in the showcase (its initial flat-lay image is created automatically).
2. Open the Interactive Flat-Lay Studio from the outfit.
3. Try one of the six quick prompts to see how editing works.
4. Type your own prompt to make the flat-lay truly yours.
5. Click Apply when the image matches the outfit you're planning.
